Advanced IIT KGP ERP Feedback Automator — Fill all feedback forms instantly and download your admit card.

## ✨ Features
- ⚡️ Fast automation of feedback forms
- 🎭 Cascading or Selective modes
- 📊 Sentiment control (Positive, Neutral, Negative)
- 🎲 Randomized realistic selections
- ⏳ Smart Delays to mimic human behavior
- 📥 Auto Admit Card download
- 🧑‍🏫 Per-Professor overrides
- 🔔 Desktop notifications
- 🔄 Auto-retry on failure
- 🧪 Dry-Run mode
- 🎨 System/Dark/Light themes
- ⌨️ Keyboard shortcuts support

## 📦 Installation

### Chrome Web Store
1. Visit the Chrome Web Store (link coming soon)
2. Click "Add to Chrome"

### Firefox Add-ons
1. Visit Mozilla Add-ons (link coming soon)
2. Click "Add to Firefox"

### Manual Installation (Developer Mode)

**Chrome / Edge:**
1. Download the latest `ferp-pro-chrome.zip` from Releases.
2. Unzip the file.
3. Go to `chrome://extensions/`
4. Enable "Developer mode" in the top right.
5. Click "Load unpacked" and select the unzipped folder.

**Firefox:**
1. Download the latest `ferp-pro-firefox.zip` from Releases.
2. Go to `about:debugging#/runtime/this-firefox`
3. Click "Load Temporary Add-on"
4. Select the `.zip` file.

## 📖 Usage Guide

### Modes
- **Cascading Mode**: Automatically fills feedback for all professors continuously.
- **Selective Mode**: Only fills feedback for the professor forms you choose to click on.

### Keyboard Shortcuts
- `Alt+Shift+S`: Start Automation
- `Alt+Shift+X`: Stop Automation

## ⚙️ Configuration
All settings can be configured via the extension popup. Settings persist across sessions.
