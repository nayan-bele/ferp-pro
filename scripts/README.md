# fERP Pro Standalone Scripts

If you do not wish to install the full browser extension, you can use these standalone scripts to quickly fill out the feedback forms.

## Scripts Available
- `positive.js`: Randomly selects rating 4 or 5 for all questions.
- `neutral.js`: Randomly selects rating 3 or 4 for all questions.
- `negative.js`: Randomly selects rating 1 or 2 for all questions.

## How to Use

1. Open the ERP feedback form for a specific professor.
2. Open your browser's Developer Tools (F12 or Ctrl+Shift+I / Cmd+Option+I).
3. Navigate to the **Console** tab.
4. Copy the entire contents of your desired script (e.g., `positive.js`).
5. Paste it into the console and press **Enter**.
6. The form will be filled automatically, and the CAPTCHA field will be focused.
7. Enter the CAPTCHA and click **Submit**.
